# layer-clipping-aggregation

本地 CPU 数值实验台：检查多客户端更新经过**分层裁剪、高斯噪声聚合、层级缩放**后的变化。
纯 Go 标准库实现（**零第三方依赖**，不调用任何外部服务），无训练、无隐私预算计算。

## 运行

```bash
go run .                         # 默认 http://127.0.0.1:8080
go run . --host 0.0.0.0 --port 9000
go run . --port 0                # 端口 0：由系统分配，启动时打印实际地址
```

打开打印的地址即可。页面提供层参数表（名称/维数/参数向量）与客户端更新表，
任何修改都会以当前种子触发整体重算（防抖提交）；非法修改返回 400，前端保留上次有效显示。

## 数值定义

设层数 L、客户端数 C、层维数 d_l、总裁剪预算 B。

- 预算分配（均保证 sum b_l^2 = B^2）：
  - equal：b_l = B/sqrt(L)（总裁剪预算按层数均分）；
  - dim_proportional：b_l = B*sqrt(d_l / sum d_j)（层预算平方与层维数成比例）。
- 逐层对每个客户端按欧氏范数裁剪：||u|| > b_l 时 clip(u) = u*b_l/||u||，否则不变。
- 噪声：对每个客户端的每个坐标加独立 N(0, sigma^2)（各层同一 sigma，可配置），再等权平均聚合。
  样本在每个重复内按「层 -> 客户端 -> 坐标」消费；sigma=0 时不消费随机数，结果与无噪声参考逐位一致。
- 层级缩放：s_l = ||theta_l|| / ||agg_l||，再施加正上限 cap。聚合范数为零时：
  - 参数范数也为 0 -> s=0（0/0 显式定义为 0，保持零向量，不产生 NaN）；
  - 参数范数 > 0 -> 使用显式有限回退系数 scale_fallback（同样受 cap 约束）。
- 重复统计：逐坐标样本均值与样本方差（自由度 R-1，R=1 时方差为 0）；
  并报告相对无噪声参考的偏差范数、MSE、RMSE 与相对误差。

固定种子下每次重复使用由 (seed, run) 确定性派生的 PCG 流，重复运行结果一致；
修改任意参数都会整体重算，不会混用旧种子的统计。

## 拒绝的输入（返回 400，保留上次有效显示）

空客户端集合、层/更新形状不一致、非正预算、负噪声 sigma、非正 cap、负回退系数、
重复次数 < 1，以及任何 NaN / ±Inf。

## 测试

    go test ./...

覆盖：两种预算分配及 sum b^2 = B^2、裁剪上界、等权聚合与层级缩放（含上限）、
零范数两种回退、手算的逐客户端噪声与消费顺序、固定种子确定性、零噪声精确回到确定性结果、
统计均值/方差手算、各类非法输入以及 HTTP/端口零集成。
