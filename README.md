# layerbench — 分层裁剪 / 噪声聚合 / 层级缩放 实验台

纯 Go（仅标准库，零第三方依赖）的本地 Web 数值实验台，用于在 Linux CPU 上
检查多客户端更新经过分层裁剪、高斯噪声聚合和层级缩放后的变化。不训练模型，
也不计算隐私预算；不调用任何外部服务。

## 运行

```bash
go run . --host 127.0.0.1 --port 8080
# 端口传 0 时由内核分配空闲端口，启动时打印实际地址：
go run . --port 0
```

打开打印出的地址即可。页面提供层参数、各客户端更新的可编辑数值表以及
预算/噪声/种子/重复次数等控件；点击“运行实验”会按当前配置与种子**完整重算**，
统计结果不会跨种子或跨配置复用。

## 计算过程

设层 \(\ell\) 维数为 \(d_\ell\)，共 \(L\) 层、\(N\) 个客户端。

1. 预算分配（都满足 \(\sum_\ell b_\ell^2 = B^2\)）：
   - 按层数均分：\(b_\ell = B/\sqrt{L}\)；
   - 平方正比于维数：\(b_\ell = B\sqrt{d_\ell/D}\)，\(D=\sum_\ell d_\ell\)。
2. 逐层按欧氏范数裁剪每个客户端更新 \(u\)：若 \(\|u\|>b_\ell\)，缩放为
   \(u\cdot b_\ell/\|u\|\)。页面显示裁剪前/后范数、是否裁剪及被裁剪比例
   \((\|u\|-b_\ell)/\|u\|\)。
3. 聚合：裁剪后的更新逐坐标等权平均；每次重复中每个客户端、每个坐标加一个
   独立的 \(\mathcal{N}(0,\sigma^2)\) 高斯量后再平均（坐标噪声方差为
   \(\sigma^2/N\)）。所有层共用同一可配置 \(\sigma\)。
4. 层级缩放：\(s_\ell=\min(\|\theta_\ell\|/\|\bar u_\ell\|,\ C)\)，最终更新为
   \(s_\ell\bar u_\ell\)。聚合范数为 0 时比值未定义，使用显式有限回退系数
   （非负且不超过上限 \(C\)），因此不会除零，结果始终有限。

输出包含无噪声参考、每次重复的聚合范数/缩放比/最终更新，以及重复实验的
均值、（总体）方差、对参考的 RMSE 与最大绝对误差。

## 确定性与拒绝规则

- 随机数使用自包含的 splitmix64 + Box-Muller 生成器（`core/rng.go`），
  按 `(种子, 重复号)` 派生；固定种子重复运行逐位一致。
- \(\sigma=0\) 时完全不走 RNG，逐位回到确定性结果（与种子无关）。
- 空客户端列表、层形状不一致、负/零预算、负 \(\sigma\)、非有限数值
  （NaN/Inf）、非法回退系数、重复次数越界等一律拒绝；HTTP 返回 400，
  页面保留上次有效结果，服务端也保留上次成功报告（`GET /api/last`）。

## 结构

- `core/`：配置校验、预算分配、裁剪、高斯 RNG、聚合、缩放与统计。
- `server/`：标准库 HTTP 服务（`POST /api/run`、`GET /api/last`、`GET /`）。
- `web/index.html`：内嵌单页界面。
- `main.go`：`--host` / `--port`（0 表示自动选端口并打印实际地址）。

## 测试

```bash
go test ./...
```

覆盖预算分配两种模式及平方和约束、裁剪（含范数恰好等于预算、零向量）、
裁剪上界（cap）与零范数回退、聚合与层级缩放、零值/零更新、重复实验统计、
固定种子可复现与零噪声精确回归，以及全部非法输入拒绝和 HTTP 端口 0 行为。
噪声用例的期望值由独立的 Python splitmix64 + Box-Muller 实现手工复算后，
以固定种子断言真实数值。
